# Smart Toilet Freshener

**Arduino · sensors · state machine**  
**Course:** Utrecht University · Interaction Technology

## Overview

Arduino prototype that uses a door sensor, motion/light detection, flush-button distance sensing and a state machine to decide when an air freshener should spray.

## Project files

- `freshener.ino` — original Arduino sketch.

## Running the project

Open `freshener.ino` in the Arduino IDE. The hardware wiring and compatible Arduino libraries are required; this project is not a standalone computer application.

## Provenance

This repository preserves **original university coursework source files**. The interactive browser adaptations in the portfolio were built later and may use different implementations. No current build or hardware compatibility is guaranteed.
